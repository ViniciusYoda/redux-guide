# Redux Shopping

Catálogo de produtos com carrinho e login demonstrativo, criado com React, TypeScript, Redux e styled-components.

## Executando o projeto

```bash
npm install
npm run dev
```

## Validação

```bash
npm run typecheck
npm run lint
npm run build
```

O Redux mantém os estados de usuário e carrinho. É possível adicionar produtos, alterar quantidades, remover itens e acompanhar o valor total.
